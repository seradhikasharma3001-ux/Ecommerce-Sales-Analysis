# E-Commerce Sales Analysis using SQL

## Project Overview
This project focuses on analyzing an e-commerce business using Microsoft SQL Server. The objective is to explore sales performance, customer behaviour, product performance, order status, payment performance, and inventory levels.

The project uses a relational database containing five tables and 54 sample records.

## Business Objectives
- Analyze order status and sales performance.
- Identify top-performing products and categories.
- Evaluate customer spending behaviour.
- Analyze payment success and failed transactions.
- Calculate Average Order Value (AOV).
- Perform order and payment reconciliation.
- Analyze inventory availability.
- Generate meaningful business insights.

## Key Business Insights
- Total Order Amount: ₹218,000
- Net Sales After Discounts: ₹209,560
- Average Order Value (AOV): ₹21,800
- Payment Success Rate: 60%
- Top-Selling Product by Gross Sales: Laptop (₹110,000)
- Highest-Sales City: Delhi (₹60,000)
- Highest-Revenue Category by Net Sales: Electronics (₹172,960)
